# AutoML dart-throw trajectory estimation

Final benchmark: `Path_Estimation_AUTOML_all_models_fully_stateful.py`. Estimates 3D trajectories from IMU measurements using QTM motion-capture trajectories as reference; errors are reported in centimetres.

Optuna selects among LSTM, GRU, BiLSTM, StatefulLSTM, StatefulGRU and SelfAttention. StatefulLSTM/GRU carry state through each complete trajectory and reset between throws; the other candidates use windows. Each split also trains an independently optimized direct-position BiLSTM baseline.

## Included files

- `Path_Estimation_AUTOML_all_models_fully_stateful.py`: preprocessing, tuning, training and evaluation.
- `loader.py`, `functions.py`: data loading and preprocessing helpers.
- `data.7z`: compressed dataset containing `dataframes_*.pkl` files (per-throw measurements) and `valid_results_*.csv` files (throw records and participant/session information).
- `requirements.txt`: Python dependencies (unpinned).

The dataset is compressed for distribution on GitHub. It covers 20 participants.

## Run

Extract `data.7z` using 7-Zip or a compatible tool. Place the extracted `.pkl` and `.csv` files directly alongside `loader.py`, not in a nested data folder. Run commands from that directory because the loader uses relative filenames.

With the 7-Zip command-line tool installed, extract using:

```sh
7z x data.7z
```

Then install dependencies in a Python environment and run:

```sh
python -m pip install -r requirements.txt
python Path_Estimation_AUTOML_all_models_fully_stateful.py
```

Defaults: 100 Optuna trials per study, epoch search over 30/50/75/100, seed 42, five unseen-participant folds, and CUDA when available (otherwise CPU). The trial budget is shared across candidate architectures. Full runs train many models and can take substantial time.

For a reduced-budget check across all splits and both methods:

```sh
python Path_Estimation_AUTOML_all_models_fully_stateful.py --trials 1 --epochs 1 --output-dir smoke_results
```

Use `--help` for options, including `--device cpu` and `--models`. Choose a fresh `--output-dir` for each run; existing benchmarks cannot be resumed through this entry point.

## Evaluation and outputs

The benchmark evaluates a random-split global model, unseen-participant folds, a global model using pooled personal splits, and eligible participants' personal models. Matched global/personal and proposed/direct comparisons use identical test throws. Models are selected on validation RMSE and refitted on training plus validation data.

Preprocessing removes empty/frozen-QTM throws and excludes the highest 20% by baseline trajectory RMSE before splitting. Results therefore describe this curated cohort. Alignment uses the initial trajectory segment, with a default alignment length of 30; this is an offline benchmark with QTM reference data.

Results are written to `output AUTOML all models fully stateful/`: split manifest, SQLite Optuna studies, selected model weights and scalers, configurations, parameter importances, test trajectories, RMSE summaries, paired comparisons and plots. These are generated by running the script and are not included in this source/data package.
